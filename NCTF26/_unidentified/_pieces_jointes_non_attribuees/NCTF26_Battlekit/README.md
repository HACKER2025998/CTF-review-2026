# Kit de préparation NCTF26

Contenu :

- `NCTF26_BATTLEBOOK.md` : méthodes et outils pour les 19 catégories, installation, KOTH, rôles et sécurité.
- `preflight.sh` : vérification **locale**, sans installation ni scan réseau.
- `tracker.csv` : tableau de suivi des challenges à compléter en équipe.
- `CHALLENGE_TEMPLATE.md` : fiche à recopier pour chaque challenge.

## Débuter

```bash
bash preflight.sh
mkdir -p ~/NCTF26/challenges
```

Les commandes de connexion du guide sont des **exemples** : renseigner uniquement les adresses réellement attribuées par la plateforme.
